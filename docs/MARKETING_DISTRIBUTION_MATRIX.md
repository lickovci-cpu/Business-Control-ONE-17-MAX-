## Content rules
- One source idea can become Post + Reel/Short + carousel + story + search article + B2B variant.
- No identical copy flooding multiple communities.
- Never invent price, inventory, references, certifications, case studies or results.
- External publishing remains approval-gated unless the specific connector is explicitly configured for autonomous publishing.
- Every published asset should retain project attribution and a measurable landing-page path.
